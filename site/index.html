Start with a command you already run

Download Motus for macOS, Linux, or Windows, or install it with Go.

Install with Go

$ go install github.com/motus-os/work-ledger/cmd/motus@latest
$ motus version

Use Motus

$ motus wrap -- npm test
$ motus finding add --run run_... --file finding.txt
$ motus finding list --query "generated file"
$ motus finding show finding_...

Read the documentation

Motus writes .motus/ledger.db at the Git root by default. Add .motus/ to .gitignore.

Share or restore the state directory. Put the search step in your agent or workflow instructions. No account or server is required.

Motus Work Ledger is open source under Apache-2.0.
