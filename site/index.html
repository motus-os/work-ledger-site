Motus Work Ledger

A work ledger for AI-assisted engineering.

Motus connects the reason behind a fix or decision to the run and Git state that informed it. Later, a developer or agent can find that context before similar work.

How it works Install Motus

Use one local ledger from a terminal, coding agent, or CI.

Try Motus on a command you run.

Download Motus for macOS, Linux, or Windows. Every release includes checksums, SBOMs, and GitHub artifact attestations.

Install from source

$ go install github.com/motus-os/work-ledger/cmd/motus@latest
$ motus version

Use Motus

$ motus wrap -- npm test
$ # Create finding.txt with one concise finding.
$ motus finding add --run run_... --file finding.txt
$ motus finding list --query "generated file"
$ motus finding show finding_...

Read the documentation

Motus writes .motus/ledger.db at the Git root by default. Add .motus/ to .gitignore.

The ledger stays local unless you choose to share it. Read the security model and stored-data details.

Motus Work Ledger is open source under Apache-2.0.
