How Motus works

  1. Record a run Wrap a test, build, script, or review. Motus keeps selected run facts.
  2. Add a finding Save an explanation, constraint, workaround, decision, or next step worth reusing.
  3. Tell agents when to search Give later agents the same ledger and add the search to AGENTS.md.
  4. Search before similar work Retrieve the finding and inspect its source run before acting.

A lesson from building Motus

One agent reviewed Motus from a shallow clone and counted 92 commits. Another checked GitHub and found 512. We recorded the mistake and the checks for the next history review.

Abridged. Motus stores run metadata, not raw output.

Recorded

$ motus wrap -- git rev-list --count HEAD
92
motus: recorded run_c703... (success)

$ motus finding add --run run_c703... \
    --format json --file finding.json
Recorded finding_9844... (open)
Finding

Shallow local history could not establish the full repository history. Next time, check the clone state and compare the same branch with GitHub.

Retrieved

$ motus finding list --state open \
    --query "repository history"
finding_9844...  open  A shallow clone of main...

$ motus finding show finding_9844...
Origin run: run_c703...  success
Summary: A shallow clone of main exposed 92...
Next step: Check whether the clone is shallow...
Before the next review

AGENTS.md tells a later agent to query Motus first. The agent sees the mistake, source run, and required check.

When repository history comes up again, the next agent starts with the known failure mode and the run that exposed it. The same workflow carries constraints, workarounds, and decisions between sessions.

Install

Download Motus for macOS, Linux, or Windows, or install with Go. Record a test, build, script, or review you already run.

Motus creates .motus/ledger.db at the Git root. Add .motus/ to .gitignore. Use one state directory wherever people, agents, scripts, or CI need the same records.

Install and record

$ go install github.com/motus-os/work-ledger/cmd/motus@latest
$ motus version
$ motus wrap -- npm test

Add and retrieve

$ motus finding add --run run_... --file finding.txt
$ motus finding list --query "repository history"
$ motus finding show finding_...

Read the documentation

Motus runs on demand, uses SQLite, and requires no account or hosted service. It does not upload the ledger or store raw command output.

Motus Work Ledger is open source under Apache-2.0.
