How Motus works

  1. Record the work Run a test, build, script, or review through Motus.
  2. Keep what matters A person, agent, or script adds an explanation, constraint, workaround, decision, or next step.
  3. Search before related work A later workflow retrieves the finding with its source run.
  4. Use it and validate Choose the next action, validate it, then close the finding with a successful recorded run.

AGENTS.md can tell coding agents to search before related work.

A finding from building Motus

An agent reported 92 commits from a shallow clone. GitHub showed 512. The command succeeded, but the conclusion was incomplete. We recorded the failure mode and the checks for the next review.

Abridged. Motus stores run metadata, not raw output.

Recorded

$ motus wrap -- git rev-list --count HEAD
92
motus: recorded run_c703... (success)

$ motus finding add --run run_c703... \
    --format json --file finding.json
Recorded finding_9844... (open)
Finding

A successful local count did not establish the repository history. Check whether the clone is shallow and compare the same branch with GitHub.

Used on the next review

$ motus finding list --state open \
    --query "repository history"
finding_9844...  open  A shallow clone of main...

$ motus finding show finding_9844...
Origin run: run_c703...  success
Summary: A shallow clone of main exposed 92...
Next step: Check whether the clone is shallow...

$ git rev-parse --is-shallow-repository
true

$ repo=motus-os/motus
$ gh api --paginate \
    "repos/$repo/commits?sha=main&per_page=100" \
    --jq '.[].sha' | wc -l
512
Changed action

The agent checks the clone and remote before reporting a count instead of trusting the successful local command.

The next review starts with the finding, checks the missing evidence, and avoids the incorrect conclusion.

Install

Download Motus for macOS, Linux, or Windows, or install with Go. Start with a command you already run.

Motus creates .motus/ledger.db at the Git root or current directory outside Git. Add .motus/ to .gitignore. Choose an explicit state directory for records shared across workspaces.

Install and record

$ go install github.com/motus-os/work-ledger/cmd/motus@latest
$ motus version
$ motus wrap -- npm test

Add and retrieve

$ motus finding add --run run_... --file finding.txt
$ motus finding list --query "repository history"
$ motus finding show finding_...

Read the documentation

Motus runs on demand, uses SQLite, and needs no account or server. It does not upload the ledger or store raw command output.

Motus Work Ledger is open source under Apache-2.0.
